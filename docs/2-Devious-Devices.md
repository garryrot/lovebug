# Devious Devices Integration

- Control inflators based on worn devices and in-game inflation status
- Control vibrators based on worn devices and in-game vibration events

## In-Game Variables

- Dynamically couple device speed to in-game
- Any [ActorValue](https://falloutck.uesp.net/wiki/Actor_Value) on the player can be used to control the speed of any action

Lots of things are different, mainly I've moved a majority of the configuraiton to json files, because its a more powerful way to configure actions than MCM, and its also less hassle for me.
